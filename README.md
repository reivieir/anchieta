# 🚀 Portal de Revisão - 2º Ano (Ensino Fundamental)

Este projeto contém uma série de jogos interativos em HTML, CSS e JavaScript criados para ajudar crianças do 2º ano do Ensino Fundamental a revisarem conteúdos escolares de forma lúdica e offline (direto no navegador do tablet ou computador).

## 📚 Conteúdos Abordados

*   **História:** Passado, presente, futuro; relógios antigos e mecânicos; linha do tempo; vida em comunidade (indígenas e quilombolas).
*   **Geografia:** Leitura de mapas e plantas de bairro; pontos de referência; extrativismo vegetal e mineral; rotina diurna e noturna.

## 🛠️ Como usar

Como o projeto é construído apenas com arquivos estáticos, não é necessário instalar nenhum servidor ou banco de dados. 

1. Acesse a página do projeto hospedada no GitHub Pages (insira seu link do GitHub Pages aqui).
2. Clique na Missão desejada.
3. Jogue pelo celular, tablet ou computador!

## 🤝 Contribuições
Sinta-se à vontade para fazer um *fork* deste projeto, adicionar novas perguntas, criar novas missões ou adaptar para outras séries escolares. O objetivo é compartilhar conhecimento e ajudar os pequenos a estudarem brincando!
